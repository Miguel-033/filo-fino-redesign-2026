# Скриншоты

`pr4-baseline/` — неизменённые снимки **старого PR №4**, только для сравнения. Они не показывают текущую доработку.

На 15 октября 2026 актуальные мобильные/desktop-снимки **не получены**. Локальные Chromium 153 и 131 завершались с SIGTRAP до открытия страницы. Облачный браузер не подключается к локальному серверу; открытие локального файла запрещено политикой браузера. Публикация или изменение `gh-pages-preview` ради обхода ограничения не выполнялись.

После запуска `verify-preview.cjs` в обычном локальном окружении здесь появятся `mobile-first.jpg`, `mobile-full.jpg`, `mobile-menu.jpg`, `mobile-process.jpg`, `mobile-gallery.jpg`, аналогичные desktop-снимки (кроме menu) и `verification.json`. Пока этих результатов нет, визуальная адаптивность и проверки реального браузера остаются непроверенными. См. команды в основном README.
