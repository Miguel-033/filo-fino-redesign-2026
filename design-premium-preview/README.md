# Filo Fino — La línea del filo

Один новый визуальный прототип для выбора направления. Только `design-premium-preview/`; действующий сайт и три прежние концепции не изменяются. Деплой не выполнялся.

## Открыть в браузере

В полном checkout ветки `codex/premium-homepage-preview`, из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте **http://127.0.0.1:8765/design-premium-preview/**. Остановка сервера: Ctrl+C. Ничего устанавливать не нужно. В изолированном архиве можно также открыть `design-premium-preview/index.html`; для корректной проверки внутренних переходов нужен полный checkout, поскольку ссылки услуг сохраняют существующие абсолютные пути сайта.

Проверьте меню и Escape, раскрытие вопросов под услугами, увеличение фотографий, стрелки и zoom в галерее, переключение четырёх этапов процесса. Галерея также поддерживает свайп; стрелки остаются альтернативой. WhatsApp и маршрут ведут во внешние приложения; проверка прототипа не отправляет сообщений.

## Визуальная идея и ограничения

Линия лезвия связывает диагональную границу Hero, срезы фотографий, кнопки и переходы. Графит, холодная сталь и латунь сочетаются с одной светлой редакционной паузой. Крупная узкая типографика уравновешена спокойным текстом; композиция услуг, галереи, процесса и контакта различается. На телефоне три услуги доступны прямыми ссылками уже на первом экране и видимыми фотографическими панелями ниже.

Семь источников, решения по ролям и список нужных кадров — в [ART_DIRECTION.md](ART_DIRECTION.md). Новая фотосессия инструментов, портрет мастера и согласованные пары до/после дадут больший выигрыш, чем дополнительные эффекты. Сейчас используются собственные файлы из репозитория; отдельные вертикальные кадры — архивные захваты процесса, не новая профессиональная съёмка.

Часы взяты из `js/site-config.js`: пн–пт 10:00–14:00 / 17:00–20:00, суббота по записи, воскресенье закрыто. В JSON-LD действующей главной указаны другие часы; перед будущей публикацией требуется уточнить расписание. В рамках прототипа старые данные не исправляются. Приход без записи в будни предусмотрен по новому заданию владельца.

GSC/GBP-экспорты в доступных материалах отсутствуют. Учтены потребности и поисковые темы из задания; цифры, позиции и гарантии не придуманы. Для японских ножей предлагается предварительная оценка, а не неподтверждённая услуга одностороннего афилования.

## Проверка

Chromium: 320, 360, 390, 430, 768, 1024, 1440 px. Проверены отсутствие горизонтального переполнения, геометрия панелей услуг, загрузка локальных шрифтов, меню/фокус, раскрытие вопросов, галерея/zoom, процесс, отсутствие ошибок JS и внешних запросов ресурсов. Проверены reduced motion и полезный HTML без JavaScript. Внешние ссылки сверены с конфигом, звонки и сообщения не выполнялись.

После просмотра скриншотов увеличен мобильный поясняющий текст, добавлены быстрые ссылки трёх услуг, убраны декоративные номера, усилен контраст Hero и исправлена высота desktop-панелей. Проверка фокуса обнаружила и помогла исправить возврат к кнопке меню вместо целевого раздела.

Не выполнялись физические тесты iOS/Safari, аудит со скринридером или Lighthouse. Это проверенный в Chromium прототип, не обещание Core Web Vitals или полной WCAG-сертификации.

## Ресурсы

Без библиотек JavaScript, сборщика, аккаунтов и платных сервисов. HTML/CSS/JS собственные. Шрифты локальные, SIL OFL 1.1; уведомления сохранены. Происхождение ресурсов — [assets/SOURCES.md](assets/SOURCES.md). `noindex, nofollow` действует только в новом прототипе; существующие метаданные, URL, sitemap, robots.txt и публикация не меняются.
