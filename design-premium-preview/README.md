# Filo Fino — La línea del filo · доработка PR №4

Отдельная доработка утверждённого прототипа из Draft PR №4 (`68d2d83dddce5a24810e580b4daa946c65ebc078`). Ветка `codex/premium-media-refinement`; изменяется только `design-premium-preview/`. Палитра графита, стали и латуни, диагональ лезвия и редакционная композиция сохранены.

## Что изменено

- Cuchillos / Peluquería / Manicura под Hero — три видимые ссылки с рамками, стрелками, hover/focus/pressed-состояниями и областью нажатия 50 px. Существующие адреса услуг сохранены.
- Усилены появления Hero, заголовков и отдельных крупных визуальных блоков; добавлены переходы этапов, открытия вопросов и микроинтеракции кнопок/стрелок. Без непрерывных анимаций, параллакса и перехвата прокрутки. Все эффекты отключаются через `prefers-reduced-motion`, включая смену настройки во время сеанса.
- В японской секции убран отдельный декоративный знак. Двухколоночная композиция на desktop, вертикальная на мобильном; запрос предварительной оценки без неподтверждённых обещаний специализации.
- Единая система WhatsApp в `premium.js`: `[Filo Fino · Web]`, перенос строки, отдельные естественные сообщения для общего вопроса, ножей, японского ножа, парикмахерских и маникюрных инструментов. HTML содержит равнозначные ссылки для работы без JS. Сообщения автоматически не отправляются.
- На главной три превью; в модальной галерее восемь настоящих кадров, круговой просмотр, счётчик 1–8, клавиатура, zoom, свайп и возврат фокуса. Для расширения дополнить массив `photographs`; первые три индекса соответствуют превью.
- Все фотографии заменены на просмотренные доступные исходники Google Drive; старые семь копий удалены только из прототипа. [Полный список и происхождение](assets/SOURCES.md), [машинный реестр](assets/media-manifest.json).
- Четыре этапа сохранены. Стабильная рамка 4:3, `object-fit: contain`, центрирование, поля; изображение не растягивается и показывается целиком. Архивные кадры обозначены как референсы, не доказательство конкретного этапа работы.
- На шаге Afilar — честная заглушка будущего видео. У входа в мастерскую — временная типографическая композиция с адресом. Видео, чужих и сгенерированных фотографий нет.
- Новый футер: телефон, WhatsApp, ссылки существующих услуг и правовых страниц, адрес/маршрут, расписание, Instagram и возврат вверх. Без магазина.
- Основные объясняющие тексты увеличены до 15–16 px, подписи — до 12–14 px. На телефоне услуги расположены вертикально, чтобы не сжимать текст и вопросы в узкие колонки. Управляющие элементы имеют видимые состояния фокуса.

Дополнительные стили собраны в `refinement.css`, подключённом после исходного `premium.css`; исходная стилистическая база сохранена.

## Открыть и проверить

Из корня **полного checkout** ветки:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/design-premium-preview/. Ctrl+C останавливает сервер. В полном checkout ссылки услуг/правовых страниц ведут на существующие файлы. Для проверки из изолированной копии или будущего GitHub Pages все корневые ссылки нужно преобразовать к `https://filofino.es/…` в копии для preview, не меняя исходную SEO-структуру.

## Проверки и скриншоты

На текущем этапе выполнены синтаксическая проверка JavaScript, разбор HTML/CSS, проверка ресурсов и ссылок, пяти контекстов WhatsApp и источников восьми изображений. Результат — [STATIC_CHECKS.md](STATIC_CHECKS.md).

**Актуальные скриншоты не получены; визуальная проверка и браузерные тесты не завершены из-за ограничений среды.** Старые снимки перемещены в [screenshots/pr4-baseline/](screenshots/pr4-baseline/) и не выдаются за текущие. Подробности — [screenshots/README.md](screenshots/README.md).

Для получения настоящих новых снимков в окружении с работающим Chromium (сервер выше должен оставаться запущенным):

```sh
npm install --prefix /tmp/filo-fino-browser-check --no-save playwright
/tmp/filo-fino-browser-check/node_modules/.bin/playwright install chromium
NODE_PATH=/tmp/filo-fino-browser-check/node_modules node design-premium-preview/verify-preview.cjs
```

Это инструменты проверки вне репозитория, не зависимости сайта. При необходимости задать `FILO_PREVIEW_URL` и `FILO_SCREENSHOT_DIR`. Сценарий проверяет 320, 360, 390, 430, 768, 1024, 1440 px; ошибки/ресурсы, горизонтальное переполнение, ссылки WhatsApp, галерею, этапы, фокус/Escape, раскрытия, reduced motion и HTML без JS. Снимки: 390 × 844 и 1440 × 1000, целая страница, меню, галерея и заглушка видео. Результаты сохраняются только после выполнения, сценарий не является доказательством успешного теста.

После запуска осмотреть снимки в оригинальном размере и исправить найденные проблемы до одобрения preview. Физические Safari/iOS и скринридер остаются отдельной проверкой.
