# Срочная корректировка мобильной композиции Hero Cuchillos

Эта корректировка заменяет прежнюю высокую мобильную композицию из docs/knife-approved. Визуальный стиль, шрифты и размеры текста, иконки, изображение, цена/срок/условия, адрес и ссылки сохранены.

- Фотообласть сокращена с 487,5 до 310 px на ширине 390.
- Отступ перед основным содержимым уменьшен с 378,3 до 44 px.
- H1 поднят с 497,3 до 157 px; остаётся поверх затемнённой фотографии.
- Цена и срок непосредственно под описанием: y=460,8–557,5 px.
- WhatsApp поднят с y=955,8 до y=569,5 px. Вся кнопка видна до y=633,5 px и в viewport 390×700, и в 390×800.
- Убраны лишние интервалы, сохранены 18 px описания и кнопки высотой 64 px.

## Скриншоты

[Первый экран 390×700](knife-compact-390x700.jpg), [первый экран 390×800](knife-compact-390x800.jpg), [весь Hero с шапкой](knife-compact-hero-full.jpg).

Первые два кадра сняты при scrollTop=0, без масштабирования, и обрезаны строго до 390×700/800. Полный Hero снят в iframe 390×1000, масштабированном облачным окном до 0,936; кадр нормализован к CSS-размеру и обрезан по нижней границе Hero (836 px вместе с шапкой). Это Chrome, не реальный iPhone/Safari.

[Измерения](viewport-matrix.json): проверены 390×700, 390×800, 390×1000, 320×800, 360×800, 430×800, 768×1000, 1440×1000; горизонтального overflow нет, изображение загружено. На 768/1440 геометрия Hero сохранена. Первый viewport содержит заголовок, стоимость, срок и полную кнопку WhatsApp; кнопка маршрута/адрес ниже основного действия.

seo/verify.py, seo/verify-interactions.cjs, seo/verify-services.cjs, render_components --check и verify.py проходят. Проверки DOM не подменяют проверку браузером; Safari/физический iPhone и Lighthouse не запускались.

Побайтно проверено сохранение остальных runtime-файлов. CSS меняется только внутри мобильного media query этого Hero; HTML меняется только номером версии CSS. Главная, другие услуги, меню, доставка, тарифы/контакты, SEO-метаданные, индексация и production не изменены. Preview сохраняет noindex,nofollow; PR #15 не объединять. Следующая страница не начиналась.
