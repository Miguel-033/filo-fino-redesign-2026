`design-premium-preview/` содержал актуальный принятый сайт, а не только прототипы: его нужные файлы **перенесены** в единый `site/`, не удалены. QA-прототипы исключены. Неиспользуемая графика и архивные фотографии владельца находятся вне публикации.

Уникальные исходные JPEG/PNG сохранены в source-materials/photos, точные дубли объединены по SHA-256. Сохранены пять мастеров активных видеодемонстраций в source-materials/videos; их браузерные MP4 остались побайтно прежними в site/assets/videos. Неиспользуемые материалы активного владельческого архива сохранены для будущего редактирования вне web source root. Тесты и установленные навыки с лицензиями сохранены. Старые стандарты/доказательства помечены историческими и не управляют новой структурой. Полная инвентаризация: file-inventory.json и source-materials/manifest.json.

## Миграция и Git

Основная карта: **65 уникальных точных URL = 42 sitemap + 23 аудита**. Дополнительные 23 включают параметры: 9 исторических HTTP 200 и 14 HTTP 404. Точные строки восстановлены из приложения B аудита через контекст проекта; полный исходный Markdown аудита в checkout отсутствовал. Это исторические наблюдения 01.11.2026, не повторный live crawl.

10 identity keep; 1 предложение 301 для /index.html; 13 возможных 301 на соответствующую услугу после проверки намерения; 41 вариант 410 или сохранения существующего 404. Все неидентичные решения явно требуют владельца. Для информационной статьи связь с тем же инструментом не означает автоматического одобрения 301. Зоны и редакционные индексы не направляются массово на главную. Три repository-only пути записаны отдельно. Никакие redirects не установлены.

Проверены все 15 PR и 17 веток redesign. Текущий результат — PR #15; основная цепочка предыдущих feature-веток включена в его историю, альтернативные прототипы отмечены отдельно. Предложение дальнейшей консолидации — ../git-consolidation.md. Базы PR, состояния старых PR и веток не менялись; force-push, переписывания истории, массового удаления и merge не было.

## Оставшиеся решения

Владельцу предстоит принять эту очистку, затем отдельно утвердить неидентичные решения карты миграции и будущий production-переход. Юридические тексты сохранены без правовой ревизии; в Aviso legal остаётся прежнее обозначение телефона «[número indicado en el sitio web]» и старое упоминание электрического оборудования — их будущая актуализация требует отдельного задания. Подтверждение часов для schema, проверка Google structured data и реальные Safari/device release checks остаются предрелизными действиями. Полная аудиопроверка пяти роликов отмечена в прежнем media provenance как ожидающая выполнения.

Новый независимый SEO-аудит, настройка redirect-ов, публикация на filofino.es, изменения основного Miguel-033/filo-fino, DNS/hosting, GBP/GSC и следующие этапы не выполнялись. После передачи результата работа останавливается для проверки владельца.
