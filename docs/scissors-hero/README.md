Навигационная подпись сокращена до «Tijeras de peluquería»; маршруты и метаданные неизменны.

## Реальные проверки

Chrome: 320, 360, 390, 430, 768, 1440 CSS px; горизонтальный overflow 0. Отдельно 390×700 и 390×800 при scrollTop=0: H1 начинается на 201 px, факты заканчиваются на 585,1 px, кнопка WhatsApp занимает 597,1–661,1 px и полностью видна на первом экране. На 390×800 также видны маршрут и адрес. Полный Hero вместе с шапкой — около 863 px.

Tab/Shift+Tab: переход между WhatsApp и Maps, видимый фокус 3 px. Сохранены исходные href и контекст обращения; сообщения не отправлялись. HTML/SEO, ресурсы/факты/ссылки семи страниц, общие компоненты и verify.py проходят. Изменения HTML вне Hero ограничены двумя подключениями CSS. Metadata/URL/noindex/общие скрипты не менялись. В консоли нет ошибок приложения.

Первые экраны 390×700/800 сняты в iframe без масштабирования и обрезаны ровно до viewport. Полный Hero и desktop снимались с масштабом облачного окна и нормализованы обратно к CSS-размерам; полный Hero обрезан по нижней границе секции. Это Chrome, не тест Safari или физического iPhone. Lighthouse/CWV не измерялись.

В сравнении с исходной иллюстрацией фотографическая область намеренно компактнее по последнему заданию. Полный H1 длиннее ножевого, поэтому масштаб настроен отдельно. На desktop нет отдельного утверждённого макета; процент точности не заявляется. Owner acceptance pending.

Production filofino.es и оригинальный репозиторий не изменены. Preview остаётся noindex,nofollow. PR #15 не объединён. Следующая услуга не начиналась.
