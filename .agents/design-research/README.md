# Filo Fino — библиотека решений для будущего веб-дизайна

Исследование от **14 октября 2026 года**. Это документация для обсуждения, не реализация сайта. Конец 2026 года ещё не наступил: подтверждены доступные сейчас примеры, а их пригодность для ноября–декабря — предварительная оценка, требующая повторной проверки перед разработкой.

## Рекомендация

Выбрать направление **«Точная мастерская»**: светлая стальная палитра, фотографии реальных инструментов и рук мастера, три понятных входа в услуги, короткий процесс и заметное обращение через WhatsApp. Более тёплое направление «Мастер и инструмент» подходит, если главным аргументом станет личность мастера; «Профессиональный сервис» — если приоритетом станут постоянные клиенты салонов.

Основу будущей реализации можно выполнить на HTML/CSS/JavaScript: CSS Grid, настоящие ссылки, нативный dialog, IntersectionObserver и input range. PhotoSwipe, Motion JS или GSAP — возможные отдельные дополнения после обоснования, не обязательный стек. Ничего из этого сейчас не устанавливалось.

## Основание решений

Прочитаны напрямую `.agents/skills/frontend-design/SKILL.md`, `ui-ux-pro-max/SKILL.md`, `web-design-guidelines/SKILL.md`, `cro/SKILL.md`; использованы local Quick Reference и Form CRO. Получены свежие Web Interface Guidelines. Это исследование вариантов, поэтому дизайн-система не генерировалась и не сохранялась через `--persist`.

Контекст взят read-only из рабочего сайта: заточка ножей, парикмахерских ножниц и инструментов маникюра/педикюра; обращения через WhatsApp; реальные работы; четыре этапа от приёмки до проверки. На существующем сайте есть также отдельная категория машинных ножей. Три первичных направления в этой записке — гипотеза информационной иерархии по заданию, не разрешение удалить остальные услуги. Их доступность надо сохранить в будущем задании.

Приоритеты — понять свою услугу, оценить результат и связаться с мастером. Преимущество этих решений для конверсии является гипотезой: пользовательские тесты и сравнение конверсий не проводились. Нельзя переносить чужие цены, сроки, гарантии или отзывы на Filo Fino.

Все рекомендации мобильной адаптации и оценки стоимости ниже — инженерная оценка. Живые демо и первичные инструкции изучены через веб-инструменты и доступные исходники; browser-render, touch-тесты, Lighthouse и профилирование на устройстве не выполнялись. Статус «рекомендуется» означает пригодность для будущего прототипирования, а не готовый проверенный компонент.
