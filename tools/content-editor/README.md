# Локальный редактор Filo Fino

## Запуск на Mac

Установите Node.js 20 или новее и FFmpeg. Если пользуетесь Homebrew:

```sh
brew install node ffmpeg
```

Из корня репозитория выполните:

```sh
./tools/content-editor/start.command
```

Редактор откроется по адресу http://127.0.0.1:4173. Держите окно терминала открытым. Для остановки нажмите Ctrl+C. Если порт занят, запустите `FILO_EDITOR_PORT=4180 ./tools/content-editor/start.command`.

## Работа с сайтом

На странице водных камней нажимайте на текст, фото или видео прямо на странице. Кнопка **+ Добавить блок** есть перед каждой секцией и после последней. В пустом разделе **Trabajo real** нажмите **+ Добавить фото или видео**. В новой галерее таким же способом можно добавить сколько угодно работ в пределах 300 карточек на страницу. Существующую секцию можно переместить или удалить. В первом экране можно менять тексты и фото, а его структура защищена.

Для общей галереи выберите **Главная · Trabajos reales**. Нажмите **+ Добавить работу**, выберите файл, название и категорию. Нажмите на существующую карточку, чтобы заменить файл, изменить название или категорию, переместить либо удалить работу.

**Предпросмотр** показывает страницу без кнопок редактора. В нём можно открыть полноразмерное фото и проверить видео. **Отменить** сбрасывает несохранённый черновик. **Сохранить** меняет HTML выбранной страницы и записывает используемые веб-копии в `assets/editor-media/`. Редактор принимает JPG, PNG, WebP и видео, включая MOV, MP4, WebM и MKV, размером до 300 МБ на файл. Фото сохраняются в WebP, видео в MP4 с H.264/AAC. Исходники на компьютере и старые медиафайлы в репозитории сохраняются. Перед остановкой сервера сохраните нужные изменения.

## Подготовка сайта к публикации

Редактор и его сервер находятся в `tools/content-editor/`. Для подготовки файлов сайта можно выполнить из корня репозитория:

```sh
node tools/content-editor/export.mjs ../filo-fino-pages
```

В новый или пустой каталог попадут только файлы сайта. Команда не обращается к GitHub. Сохранение в редакторе и локальная сборка не публикуют сайт. Для GitHub Pages используйте содержимое экспортированного каталога и отдельное подтверждение публикации.
