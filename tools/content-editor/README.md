# Локальный редактор Filo Fino

## Запуск на Mac

Установите Node.js 20 или новее и FFmpeg. Если пользуетесь Homebrew:

```sh
brew install node ffmpeg
```

Из корня репозитория выполните:

```sh
./tools/content-editor/start.command
```

Редактор откроется по адресу http://127.0.0.1:4173. Держите окно терминала открытым. Для остановки нажмите Ctrl+C. Если порт занят, запустите `FILO_EDITOR_PORT=4180 ./tools/content-editor/start.command`.

## Работа с сайтом

На странице водных камней нажимайте на текст, фото или видео прямо на странице. Кнопка **+ Добавить блок** есть перед каждой секцией и после последней. В пустом разделе **Trabajo real** нажмите **+ Добавить фото или видео**. В новой галерее таким же способом можно добавить сколько угодно работ в пределах 300 карточек на страницу. Существующую секцию можно переместить или удалить. В первом экране можно менять тексты и фото, а его структура защищена.

Чтобы добавить медиа в существующий блок на странице водных камней, нажмите **Редактировать секцию** над ним и выберите **Добавить фото** или **Добавить видео**. Там же можно поменять медиа и текст местами. Возьмитесь за ручку **↕**, чтобы перетащить секцию, карточку галереи или элемент внутри секции. Нажатие на ручку открывает кнопки **Вверх** и **Вниз**. Если ручка в фокусе, можно использовать клавиши со стрелками.

Для общей галереи выберите **Главная · Trabajos reales**. Нажмите **+ Добавить работу**, выберите файл, название и категорию. Нажмите на существующую карточку, чтобы заменить файл, изменить название или категорию, переместить либо удалить работу.

**Предпросмотр** показывает страницу без кнопок редактора. В нём можно открыть полноразмерное фото и проверить видео. **Отменить** сбрасывает несохранённый черновик. **Сохранить локально** меняет HTML выбранной страницы и записывает используемые веб-копии в `assets/editor-media/`. Редактор принимает JPG, PNG, WebP и видео, включая MOV, MP4, WebM и MKV, размером до 300 МБ на файл. Видео сохраняются в MP4 с H.264/AAC. Для фото и обложек используется WebP, если его кодировщик есть в FFmpeg. В остальных случаях редактор использует JPEG или PNG для прозрачных изображений. Исходники на компьютере и старые медиафайлы в репозитории сохраняются. Перед остановкой сервера сохраните нужные изменения.

## Публикация на GitHub Pages preview

Измените фото, текст или видео и нажмите **Сохранить локально**. Нажмите **Опубликовать на GitHub Pages**, проверьте список файлов и нажмите **Подтвердить и опубликовать**. После подтверждения редактор отправляет статическую сборку в `gh-pages-preview`, ждёт ответа GitHub Pages и показывает ссылку, когда обновлённая страница доступна. Оставьте сервер редактора запущенным. Если GitHub не подтвердит публикацию за пять минут, редактор покажет коммит и ссылку на журнал сборки.

Редактор работает из ветки `codex/local-content-editor` репозитория `Miguel-033/filo-fino-redesign-2026`. Для публикации используется существующая авторизация Git на компьютере и право записи в `gh-pages-preview`. Если Git уже работает с вашим аккаунтом, дополнительная авторизация не нужна. Для HTTPS можно один раз войти через GitHub CLI:

```sh
gh auth login --hostname github.com --git-protocol https
gh auth setup-git --hostname github.com
```

Если команды `gh` нет, установите её через `brew install gh`. При использовании SSH достаточно действующего ключа GitHub. Для создания коммита должны быть настроены `git config user.name` и `git config user.email`.

Если GitHub отклонит отправку, посмотрите причину в диалоге и строку `[Filo Fino] Git push` в Терминале. После восстановления доступа можно повторить подтверждение, пока проверенная сборка действительна и ветка preview не менялась.

В **Settings → Pages** этого репозитория источник должен быть **Deploy from a branch**, ветка **gh-pages-preview**, папка **/(root)**. Preview должен открываться по адресу https://miguel-033.github.io/filo-fino-redesign-2026/ без перенаправления на другой домен. Если push прошёл, но сборка не запустилась, проверьте в **Actions** запуск для указанного коммита, право записи в ветку и подтверждение почты учётной записи GitHub. При конфликте редактор остановится и укажет файл. Новые медиа для публикации ограничены 100 МБ на файл.

В ветку preview попадают изменения двух редактируемых страниц, стили мозаики и страницы водных камней при наличии правок и медиа, на которые ссылаются страницы. Остальные файлы берутся из текущей ветки preview. Файлы редактора остаются в его ветке.

Для отдельной локальной сборки, без отправки в GitHub:

```sh
node tools/content-editor/export.mjs ../filo-fino-pages
```
