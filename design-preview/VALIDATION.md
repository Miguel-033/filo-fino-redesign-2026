# Проверка прототипов

Дата: 14 октября 2026. Использованы frontend-design, ui-ux-pro-max, cro, site-architecture, copywriting и web-design-guidelines через прямое чтение файлов. Прочитаны три направления исследования, выбранные компоненты и критерии mobile/performance; текущие Web Interface Guidelines получены read-only через GitHub. UI/UX design-system search выполнен без persist; его общий blue/SaaS результат не принят как готовая концепция мастерской, предпочтение отдано предметному исследованию.

## Браузерные проверки

Chromium через имеющийся Playwright, без установки браузерных пакетов. Изначальный sandbox запрещал localhost sockets и запуск Chromium; автоматическая проверка разрешила расширенный локальный запуск. Управляемый браузер запрещает file://, поэтому использован только сервер на 127.0.0.1. Это не внешний хостинг.

Для A, B и C проверены **320, 360, 390, 430, 768 и 1440 px**: всего 18 сценариев. На каждой ширине:

- Ширина документа не превышает viewport; три ссылки основных услуг остаются в DOM и видимом вертикальном потоке.
- Нет сломанных загруженных изображений и ошибок JavaScript. Отложенные внеэкраные изображения не объявляются сломанными только потому, что lazy loading ещё не начался.
- Меню открывается, Escape закрывает его, фокус возвращается к кнопке открытия.
- Gallery-dialog открывается; ArrowRight переключает изображение, Escape закрывает.
- A: переключение этапа обновляет описание. C: выбор симптома обновляет подсказку и выделяет соответствующую услугу без удаления остальных.

На 390 px отдельно проверены reduced-motion и отключённый JavaScript: content не скрывается. Для скриншотов страница прокручена, чтобы раскрыть reveal-блоки, затем возвращена к началу. Сохранены 6 реальных JPEG-снимков: первый экран 390×844 и полная страница каждого варианта.

Просмотрены первые экраны всех трёх вариантов. После первого прохода уменьшены mobile hero/фото/карточки A, чтобы третье направление не пряталось под нижний контакт. В B добавлен архивный кадр проверки реза в процесс. Декоративные Unicode arrows заменены собственными SVG для надёжного отображения. Проверки повторены после этих изменений.

## Что не проверено

Headless Chromium с touch emulation — не физический iPhone/Android, не Safari и не тест screen reader. Не выполнялись полноценный WCAG-аудит, измерения field CWV, Lighthouse, GPU/CPU benchmark, реальная запись/передача WhatsApp, телефонные звонки или тест обращения с клиентами. Рекомендация A остаётся дизайнерской гипотезой. SEO-эффективность не измерялась; preview намеренно noindex.
