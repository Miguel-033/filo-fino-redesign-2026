# Filo Fino — три изолированных прототипа

## Открыть в браузере

Скачайте ветку этого PR или откройте рабочую копию. Из корня репозитория:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем:

- A: http://127.0.0.1:8765/design-preview/concept-a.html
- B: http://127.0.0.1:8765/design-preview/concept-b.html
- C: http://127.0.0.1:8765/design-preview/concept-c.html

Сервер только локальный; это не деплой. На своём компьютере страницы можно также открыть двойным щелчком: CSS/JS/фото находятся рядом. Управляемый Chromium этой среды запрещает file://, поэтому проверка проведена через localhost. GitHub показывает HTML как исходник, а не как работающую страницу. Не добавляйте GitHub Pages для этих демонстраций.

## Сравнение

| Вариант | Реальное отличие композиции | Сильная сторона | Ограничение |
| --- | --- | --- | --- |
| A — Точная мастерская | Холодная светлая палитра, собранная sans-типографика, узкий предметный hero, асимметричная галерея, переключаемые этапы | Баланс ясного выбора и профессионального характера; подходит всем трём аудиториям | Для премиальной финальной версии нужны более качественные собственные предметные кадры |
| B — Мастер и инструмент | Serif-заголовки, тёплая поверхность, арочный кадр деревянной вывески, открытые строки услуг, фотография мастерской как печатный снимок, тёмный блок процесса | Самое выраженное ощущение реального места и ремесла | Нет согласованного портрета мастера и полноценных фото всех этапов; чуть длиннее путь через историю |
| C — Профессиональный сервис | Компактная тёмная панель симптомов, интерактивная подсказка без скрытия услуг, blue-иерархия, отдельный вход для повторного обращения, линейный процесс | Быстрее ориентирует клиента по проблеме и следующему действию | Менее эмоциональный образ мастерской; подсказка не является диагностикой |

Предварительная рекомендация — **A** как основа будущей главной: все три услуги доступны обычными ссылками, реальная фотография поддерживает характер, заметный контакт не мешает центральным маршрутам. Из B позже можно развить блок доверия через мастера, сохраняя единую композицию A. C полезен как альтернативный приоритет для повторных профессиональных клиентов. Это оценка дизайна, не доказанный выигрыш SEO/конверсии: пользовательский тест и field-аналитика не проводились.

## Взаимодействия и технический выбор

Общие: боковое dialog-меню, close/Escape, возврат фокуса, gallery-dialog с предыдущим/следующим кадром и стрелками клавиатуры, реальные ссылки, нижний контакт, одноразовый reveal. A: интерактивные четыре этапа. C: выбор симптома подсвечивает соответствующий сервис и объясняет рекомендацию, не прячет другие направления.

HTML/CSS/vanilla JS; **никаких новых JS-библиотек, webfonts, paid services или tracking scripts**. Системные font stacks: sans для A, Georgia + sans для B, system-ui для C. CSS Grid и media queries работают на mobile/tablet/desktop. Есть skip-link, alt, accessible names, focus-visible, aria-pressed, live descriptions, reduced-motion. Основные content/links остаются доступны без JS. При reduced-motion нет reveal-перемещения и drawer animation. В демо не добавлена искусственная before/after-пара: имеющиеся кадры не являются совпадающими по ракурсу фотографиями для честного comparison slider.
