# Filo Fino — принятая дизайн-система

Единственный web source root — `site/`. Принятое состояние: b2cf0a7 (Hero главной), 89f466f (Hostelería), efbac65 (верхние интервалы Manicura/Cuchillas), предыдущие принятые ножи/ножницы. В этой очистке визуальный редизайн не разрешён.

Сохранены графитовый фон, золотистые акценты, локальные Barlow Condensed/Manrope, индивидуальные фотографии, градиенты и кадрирование шести Hero. Файлы CSS/JS/активных медиа и HTML Hero защищены хешами `seo/accepted-design.json`. Не применять прежние размеры CTA из исторического стандарта поверх последних принятых локальных правил.

Общие header/footer/menu: `design-system/components/`; материализация `python design-system/render_components.py`, сверка с `--check`. Footer больше не содержит Consejos del taller; три legal-ссылки локальны. Меню, фотографии, карточки, процесс, иллюстрированный блок отправки и модальное окно сохранены. Юридические статьи используют общие компоненты и локальные стили без Bootstrap/AOS; их текст не переписан.

Сайт без framework, внешних автоматических CSS/JS/font загрузок и новых аналитических SDK. Ссылки работают в HTML без JS; JS улучшает меню/диалоги/этапы. Не менять цены/сроки ради композиции. Не скрывать текст и не допускать пересечений.

Проверки: `python seo/verify.py`, `node seo/verify-services.cjs`, `node seo/verify-interactions.cjs`. Историческая спецификация сохранена в `docs/history/DESIGN_SYSTEM_2026-10-16.md` и не заменяет последние принятые Hero.
